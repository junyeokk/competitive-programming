# competitive-programming

알고리즘 문제 풀이 모음.

| 폴더 | 내용 | 관리 |
| --- | --- | --- |
| `baekjoon/` | 백준 (Bronze ~ Platinum) | BaekjoonHub 자동 |
| `programmers/` | 프로그래머스 (레벨 0 ~ 4) | BaekjoonHub 자동 |
| `goormlevel/` | 구름LEVEL | BaekjoonHub 자동 |
| `study/코더스아이티/` | 코더스아이티 Pass 과정 | 수동 |
| `study/이것이_코딩테스트다/` | 이것이 코딩 테스트다 | 수동 |
| `archive/` | 예전 풀이 (codeforces, codechef, leetcode, 백준 C++) | 보관용 |
| `templates/` | 코드 템플릿 | 수동 |

`baekjoon/`, `programmers/`, `goormlevel/`은 BaekjoonHub가 push하는 경로다. 확장 설정의 Directory Path Template을 `baekjoon/${level}/${id}. ${title}`, `programmers/${level}/${id}. ${title}`으로 맞춰 두었으니, 폴더명을 바꾸면 템플릿도 같이 바꾼다.
